# 안녕하세요, 정민혁입니다

컴퓨터시스템공학과를 졸업했고, IoT/임베디드 하드웨어와 머신러닝·딥러닝 모델을 함께 다루는 것을 좋아합니다.
팀에서는 주로 Back-end와 모델 구현, 그리고 하드웨어-소프트웨어·프론트-백엔드처럼 서로 다른 파트를 잇는 역할을 맡아왔습니다.

- 관심 분야: 온디바이스·임베디드 AI, AI 백엔드 / ML 엔지니어링
